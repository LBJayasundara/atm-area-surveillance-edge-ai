# ATM Area Surveillance Edge AI System

Real-time suspicious activity detection for ATM/banking environments using Edge AI on Raspberry Pi with mobile alerting.

## Status

🚧 **Under Development** - Complete implementation coming soon!

## Overview

This project implements an intelligent surveillance system that:
- Detects weapons (guns, knives) in real-time
- Identifies face concealment (helmets, masks)
- Monitors loitering behavior near ATMs
- Sends instant alerts to mobile app
- Runs entirely on Raspberry Pi 4 (Edge AI)

## Tech Stack

- **Edge AI**: Python, OpenCV, YOLOv8, ByteTrack
- **Mobile App**: Flutter
- **API**: Flask REST API
- **Hardware**: Raspberry Pi 4, IP CCTV Camera
